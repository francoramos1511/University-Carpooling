University Carpooling 🚗🎓

University Carpooling is an MVP (Minimum Viable Product) of a university carpooling mobile application, aimed at connecting students who offer rides with students who need transportation. The project was developed as a Mini Project for the Software Engineering 1 (ISA1) course at Universidad ORT Uruguay, with a focus on applying agile project management practices rather than on building functional code.

Unlike a traditional software development project, the emphasis here was on the process: problem definition, requirements gathering, Figma prototyping, and iterative validation with users and sponsors.

Project Approach

The project did not consist of building a fully functional coded application, but rather simulating a complete agile product development cycle:

Problem identification and target audience definition
Competitor analysis
Stakeholder identification
Definition of functional and non-functional requirements
Interactive prototyping in Figma
Validation with real users and project sponsors
Methodology

Framework: SCRUM

The team worked across 4 two-week iterations, applying classic Scrum ceremonies:

Sprint Planning – defining sprint goals, selecting user stories, and estimating effort with Planning Poker
Daily Scrum – short check-ins (2-3 times per week, via Discord/WhatsApp)
Sprint Review – presenting prototypes to classmates and sponsors
Sprint Retrospective – continuous improvement analysis at the end of each sprint
Management Artifacts
Product Backlog prioritized by value
Definition of Done and Definition of Ready
Increments delivered as validated Figma prototypes

The value of the continuous iteration Scrum promotes for adjusting product direction
Using Figma as a tool for fast, visual prototyping
The importance of prioritizing the backlog based on value delivered to the client
