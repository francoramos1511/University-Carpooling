# 🚗🎓 University Carpooling

University Carpooling is an MVP of a mobile university carpooling application designed to connect students who offer rides with students who need transportation.

The project was developed as a Mini Project for the **Software Engineering 1 (ISA1)** course at **Universidad ORT Uruguay**, focusing on agile product development, requirements analysis, prototyping, and user validation rather than implementing a fully functional application.

---

## 🎯 Project Overview

The project simulated a complete agile product development cycle, from identifying the problem to validating the proposed solution with users and sponsors.

### Main Activities

- Problem identification and target audience definition
- Competitor analysis
- Stakeholder identification
- Functional and non-functional requirements definition
- User Stories and Product Backlog creation
- Interactive prototyping with Figma
- User and sponsor validation
- Iterative product refinement

---

## 🔄 Methodology

The project followed the **SCRUM framework** across **4 two-week iterations**.

### Scrum Practices

- **Sprint Planning** – Sprint goals, User Stories, and effort estimation using Planning Poker
- **Daily Scrum** – Short team meetings held 2–3 times per week through Discord/WhatsApp
- **Sprint Review** – Prototype presentations and feedback collection from classmates and sponsors
- **Sprint Retrospective** – Analysis of the iteration and identification of improvement opportunities

### Management Artifacts

- Product Backlog prioritized by business value
- Definition of Ready (DoR)
- Definition of Done (DoD)
- Validated Figma prototypes as project increments
